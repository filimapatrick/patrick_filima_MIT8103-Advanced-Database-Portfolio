-- ============================================================================
-- Scenario:
--   PostgreSQL achieves high-concurrency ACID transactions via Multi-Version
--   Concurrency Control (MVCC) rather than traditional read/write locks.
--   Every row (tuple) in PostgreSQL contains hidden system attributes:
--     - xmin: The transaction identifier (XID) of the inserting transaction.
--     - xmax: The transaction identifier (XID) of the updating/deleting transaction (0 if current).
